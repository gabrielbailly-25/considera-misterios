# Consideración de los misterios - versión con doble audio

Esta versión parte de la web https://gabrielbailly.github.io/considera-misterios/ y añade un switch para elegir entre:

- Grabación original
- Voz IA

## Audios originales
Se siguen reproduciendo directamente desde el repositorio público actual.

## Audios IA
Coloca en `audios-ia/` los archivos:

- `gozosos.wav`
- `dolorosos.wav`
- `luminosos.wav`
- `gloriosos.wav`

El usuario puede cambiar de versión con el switch. Si lo hace durante la reproducción, la app conserva el mismo grupo e intenta mantener el punto temporal.

## Publicación
Copia estos archivos al repositorio que sirve GitHub Pages. Si sustituyes la web actual, conserva una copia de seguridad antes.
